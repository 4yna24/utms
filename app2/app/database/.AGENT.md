# Database Directory - Coding Rules

**Location**: `app/database/`  
**Purpose**: Data access layer with repositories and adapters  
**Status**: Phase 1 complete (ApplicationRepository created)

## Structure
- `__init__.py` - Export repository getter functions
- `adapters.py` - SQLAlchemy implementation (legacy string-based pattern)
- `interfaces.py` - Repository interfaces (IUserRepository, ILowLevelDatabase, IHighLevelDatabase)
- `application_repository.py` - Typed Application data access (PREFERRED for new code)

## EXPLICIT CODING RULES

### ✅ DO:
1. **Use typed repository methods** - Call `get_application_repository()` for Application queries
2. **Return OperationResult** - All repository methods return OperationResult with error codes
3. **Use selectinload for relationships** - Eager load related data to avoid N+1 queries
4. **Handle SQLAlchemy exceptions** - Convert db errors to appropriate ErrorCode
5. **Centralize queries here** - All model queries belong in repositories, NOT scattered in routes/services

### ❌ DO NOT:
1. **String-based dispatch** - Never create new methods that take action_name strings
2. **Direct db.session in classes** - Only repositories touch db.session, business classes use repositories
3. **Query logic in routes** - Move all Application.query to ApplicationRepository methods
4. **Bare None returns** - Wrap errors in OperationResult, never return None without context
5. **Loose error handling** - Catch exceptions and convert to specific ErrorCode

## Pattern: Correct Repository Method

```python
def find_by_id(self, application_id: int) -> OperationResult:
    try:
        app = db.session.get(Application, application_id)
        if app is None:
            return OperationResult.error(
                ErrorCode.NOT_FOUND,
                f"Application {application_id} not found"
            )
        return OperationResult.ok(data=app)
    except Exception as e:
        return OperationResult.error(ErrorCode.DB_ERROR, str(e))
```

## Anti-Pattern: What NOT to Do

```python
# ❌ WRONG - String-based dispatch
def execute_query(self, action: str, payload: dict):
    if action == "find_app":
        return Application.query.get(payload["id"])
    elif action == "create_app":
        app = Application(**payload)
        db.session.add(app)
        db.session.commit()
        return app

# ❌ WRONG - No error handling
def find_by_id(self, app_id: int) -> Application | None:
    return Application.query.get(app_id)  # Returns None silently

# ❌ WRONG - Query logic in route
from app.models import Application
app = Application.query.filter_by(applicant_id=user_id).first()
```

## Available Repositories

**ApplicationRepository** (via `get_application_repository()`)
- find_by_applicant_id(id) → OperationResult
- find_by_id(id) → OperationResult
- create(applicant_id, **kwargs) → OperationResult
- update(application) → OperationResult
- update_status(app_id, status) → OperationResult
- commit() → OperationResult
- rollback() → OperationResult
- get_pending_for_dean/oidb/ydyo() → OperationResult
- delete_documents(app_id) → OperationResult
- get_by_status(status) → OperationResult

**UserRepository** (via `get_user_data_interface()`)
- find_by_email_role(email, role) → User | None (legacy)
- find_by_id(id) → User | None (legacy)
- create_user(email, password, role) → OperationResult

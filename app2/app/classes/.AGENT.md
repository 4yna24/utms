# Classes Directory - Coding Rules

**Location**: `app/classes/`  
**Purpose**: Business logic layer with role-specific operations  
**Status**: Phase 1 complete (users.py split and repositories integrated)

## Structure
- `auth.py` - Authentication logic
- `users/` - Role-specific classes (Applicant, DeanOffice, Oidb, Ydyo, YGK)
- `entities/` - Entity definitions (Application, Document)
- `interfaces.py` - Domain contracts (IReviewer, IDocumentHandler)

## EXPLICIT CODING RULES

### ✅ DO:
1. **Use repository interfaces** - All data access through `get_application_repository()` or `get_user_data_interface()`
2. **Return OperationResult** - Every method returns OperationResult with success/error_code/data/error_msg
3. **Specific error codes** - Use ErrorCode.VALIDATION_FAILED, NOT_FOUND, etc. (never bare error messages)
4. **Implement domain contracts** - Classes must implement IReviewer or IDocumentHandler if applicable
5. **Handle exceptions** - Catch and convert to OperationResult with appropriate ErrorCode

### ❌ DO NOT:
1. **Direct db.session** - Never import db directly or call db.session.add/commit/rollback
2. **Direct model queries** - Never use Application.query.filter() or similar; use repository
3. **Bare bool returns** - Never return True/False without context; wrap in OperationResult
4. **Form parsing** - Move form handling to routes/services, not here
5. **File I/O** - File operations belong in services, not business classes

## Pattern: Correct Repository Usage

```python
def submit(self, form_data: dict, ...) -> OperationResult:
    # Get repository
    app_repo = get_application_repository()
    
    # Check existing via repository
    result = app_repo.find_by_applicant_id(self.user_id)
    if result.success and result.data is not None:
        return OperationResult.error(ErrorCode.APPLICATION_EXISTS, "Already submitted")
    
    # Create via repository
    create_result = app_repo.create(applicant_id=self.user_id, status="submitted")
    if not create_result.success:
        return create_result
    
    # Commit via repository
    return app_repo.commit()
```

## Anti-Pattern: What NOT to Do

```python
# ❌ WRONG - Direct db.session
from app import db
app = db.session.query(Application).filter(...).first()
db.session.add(something)
db.session.commit()

# ❌ WRONG - Bare bool return
def validate_form(self, data: dict) -> bool:
    return "email" in data

# ❌ WRONG - Form parsing in class
@staticmethod
def parse_form_data(form):
    return {"email": form.get("email"), ...}
```
